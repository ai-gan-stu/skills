# 获取哔哩哔哩视频字幕

用本技能目录中的 `scripts/get_subtitle.py` 取出字幕。视频链接和保存位置由调用方提供。

## 步骤

1. 在本技能目录执行 `pip install -r requirements.txt`。需要 Python 3.11 或更高版本。
2. 执行 `python scripts/get_subtitle.py <BV号或视频链接>`。分 P 用 `-p`；链接里已有 `p=` 时不传。指定纯文本路径用 `-o`。
3. 不传 `-o` 时，在当前目录得到 `BV号.txt` 和 `BV号_时间戳.txt`。传了 `-o` 时，带时间戳的文件与纯文本同目录，扩展名前加 `_时间戳`。
4. 把两份 UTF-8 文本都交给调用方，并说明文件路径。纯文本是标题加逐句正文。带时间戳的文本在每句前写开始时间，只保留到秒：视频不超过 1 小时用 `[MM:SS]`；视频超过 1 小时后，满 1 小时的句子用 `[HH:MM:SS]`。

## 注意事项

- 只运行已有脚本，不要重写抓取逻辑，也不要写入还原地址的参数。
- 脚本失败时，转述标准错误中的原文，不要改用别的抓取方式。
